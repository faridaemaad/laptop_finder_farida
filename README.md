# Student Laptop Finder

A responsive web app to browse laptops, search and filter them, view full specifications, save favorites, and compare them side by side. Built with JavaScript (ES modules) and Tailwind CSS 4.

## Requirements
- Node.js and npm
- VS Code with the Live Server extension

## Install
npm install

## Build the CSS
npm run build

For development (rebuilds CSS automatically when you edit files):
npm run dev

## Run
Open the project folder in VS Code, right-click `index.html`, and choose "Open with Live Server".
A local server is required because the app loads data with fetch().

## Pages
- index.html: home page and live statistics
- laptops.html: catalogue with search, filters, and sorting
- details.html?id=1: details of one laptop
- favorites.html: saved favorites
- compare.html: side-by-side comparison
